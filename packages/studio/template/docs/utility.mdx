title: Utility Designs
---

- [**Bonny**](/editor/#s={"design"%3A"bonny"}): Drafts a body outline based on measurements
- [**Legend**](/editor/#s={"design"%3A"legend"}): Used to document pattern notation
- [**Library**](/editor/#s={"design"%3A"library"}): FreeSewing's library of re-usable pattern parts
- [**Examples**](/editor/#s={"design"%3A"examples"}): Example code for advanced use-cases, including:
  - **Library polymorphism**: Re-use a library part multiple times in different ways
  - **Stack layout**: Use different stacks to layer your design
- [**Rendertest**](/editor/#s={"design"%3A"rendertest"%2C"view"%3A"draft"}): See all styles, useful for themeing

:::note
Our [developer documentation](https://freesewing.dev/) includes many examples
for our [core API](https://freesewing.dev/).
The [**Examples**](/editor/#s={"design"%3A"examples"}) design included here
holds example code for more advanced use-cases that is difficult to integrate
in our documentation.
:::
