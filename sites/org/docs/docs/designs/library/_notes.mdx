The FreeSewing Library is not a design that you can directly, turn into a pattern.
Instead, the library contains reuseable pattern parts that can be used by (aspiring)
pattern designers.

The reason we include it in our collection is to improve visibility, so that people
know they can reuse these building blocks.

As an end user, you typically cannot use the library as the various parts contained
in it require specific information to be passed by the pattern the uses them.
