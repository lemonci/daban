**The type of waistband**

This option changes the type of waistband for the pants. There are
three types:

- Standard:
  The waistband is a strip of fabric along the top of the pants. This
  is how most pants are constructed.
- Elastic:
  The waistband is constructed like the standard way, but with two
  exceptions: there is a little extra room generated in the back,
  and there should be a piece of elastic incorporated in the back of the
  waistband. This allows for a more flexible fit.
- Ribknit:
  The waistband is replaced by a band of ribknit fabric. Two small pieces
  of fabric are added to the front to create a space for the button and
  buttonhole.
