---
title: 'Leglengthcustom'
sidebar_class_name: hidden
---

Set your own pant leg length. This is a percentage of the waist to floor
measurement. The value can range from 40% to 100%. The default is 95%,
which is what the Long setting uses too.

:::note
This setting is only available if the Leg Length option is set to
'custom'.
:::
