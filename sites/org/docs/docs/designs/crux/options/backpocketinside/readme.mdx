---
title: 'Backpocketinside'
sidebar_class_name: hidden
---

Normally the pockets are patch pockets on the outside of the garment,
with the pocket opening part of the pocket fabric.

This option allows you to move the pocket to the inside of the garment,
with the opening part of the fabric of the back.

:::note
The 'square' version of the back pocket can only be on the outside.
:::
