Ashley extends [the Titan block](https://freesewing.org/designs/titan). Much of its code is directly lifted from [Percy](https://freesewing.org/designs/percy), for cutting the legs short, drafting the pockets, and automatically setting a curve for the waistband (though Ashley adds a more dramatic curve to the back waistband only instead of curving all the waistband pieces). The fly pieces and belt loops are pilfered from [Charlie](https://freesewing.org/designs/charlie).

The big new thing Ashley does is add a yoke to the back pieces for some extra shaping at your butt. This is a common detail on jeans.
