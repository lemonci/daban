---
title: 'Fit Legs'
---

This option determines the approach the software uses for fitting the cross-seam.

At 0%, the cross-seam is increased by purely moving the inseam sideways and increasing the horizontal width
of the fabric parts. This can result in wide legs.

At 0% the bottom of the legs is kept straight and perpendicular to the fabric grain,
which can be an advantage if you're using patterned fabric.

At 100%, the cross-seam is increased only by rotating the inseam around the outseam.
This will try to keep your legs fitted but will lower the inseam relative to the outseam,
creating a somewhat curved hem.

Option values between 0% and 100% will interpolate between both methods.
