## What You Need {#needs}

To make Sarah, you will need the following:

- [Basic sewing supplies](/docs/sewing/basic-sewing-supplies)
- About 3 meters (3.3 yards) of a suitable main fabric (see [Fabric
  Options](#fabric))
- Bias tape and/or a bias tape maker (optional)

## Fabric Options {#fabric}

### Main Fabric

A somewhat thicker jersey knit is ideal, but any stretchy fabric would work. If you intend to use woven fabric, you'll have to add some kind of closure. Thin jersey may sag a bit under its own weight.

## Cutting Instructions {#cutting}

- Cut one **front inside** part on fold.
- Cut two **pocket** pieces. Use a contrasting color/pattern if you want, since this side will face inward.
- Cut two of all other parts.
