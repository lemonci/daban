Hannah is just _Toni_ with a three-part-hood.

To create Hannah, follow [Toni's instructions](/docs/designs/toni/instructions/),
leaving the neck opening unfinished and keeping standard seam allowance there.

Next, create and attach the hood using steps 5–8 from the [Hugo instructions](/docs/designs/hugo/instructions/).

:::tip
You can alternatively also use steps 7–10 from the [Yuri instructions](/docs/designs/yuri/instructions/) to create and attach the Hood.
:::

Good luck!
