## Conditional Options {#conditional}
### Biceps ease {#bicepsease}

**The amount of ease at your upper arm. Note that while we try to respect this, fitting the sleeve to the armhole takes precedence over respecting the exact amount of ease.**
- Type: **Percentage**
- Default: **15%**
- Minimum: **-10%**
- Maximum: **30%**

<Bicepsease />

### Sleeve length (Dolman) {#dolmansleevelength}

**The length of the sleeve as a percentage of the distance from the shoulder to the wrist**
- Type: **Percentage**
- Default: **30%**
- Minimum: **1%**
- Maximum: **120%**

<Dolmansleevelength />

### Sleeve length {#sleevelength}

**The length of the sleeve as a percentage of the distance from the shoulder to the wrist**
- Type: **Percentage**
- Default: **30%**
- Minimum: **10%**
- Maximum: **120%**

<Sleevelength />

### Wrist ease {#wristease}

**The amount of ease at your wrist**
- Type: **Percentage**
- Default: **20%**
- Minimum: **-15%**
- Maximum: **200%**

<Wristease />

### Opening seam allowance {#holeallowance}

**The size of the seam allowance for neck, arm openings as a percentage of the seam allowance**
- Type: **Percentage**
- Default: **0%**
- Minimum: **0%**
- Maximum: **100%**

<Holeallowance />

### Raglan angle (back) {#raglanangleback}

**The angle of the raglan back seam**
- Type: **Degrees**
- Default: **15°**
- Minimum: **0°**
- Maximum: **25°**

<Raglanangleback />

### Raglan angle (front) {#raglananglefront}

**The angle of the raglan front seam**
- Type: **Degrees**
- Default: **20°**
- Minimum: **0°**
- Maximum: **30°**

<Raglananglefront />

### Raglan offset (back) {#raglanoffsetback}

**The offset of the raglan back seam**
- Type: **Percentage**
- Default: **24%**
- Minimum: **1%**
- Maximum: **99%**

<Raglanoffsetback />

### Raglan offset (front) {#raglanoffsetfront}

**The offset of the raglan front seam**
- Type: **Percentage**
- Default: **33%**
- Minimum: **1%**
- Maximum: **99%**

<Raglanoffsetfront />

### Arm opening pitch (back) {#sleevelessopeningpitchback}

**The curve on the back of the arm opening for sleeveless designs**
- Type: **Percentage**
- Default: **80%**
- Minimum: **60%**
- Maximum: **90%**

<Sleevelessopeningpitchback />

### Arm opening pitch (front) {#sleevelessopeningpitchfront}

**The curve on the front of the arm opening for sleeveless designs**
- Type: **Percentage**
- Default: **100%**
- Minimum: **70%**
- Maximum: **120%**

<Sleevelessopeningpitchfront />

### Arm opening size {#sleevelessopeningsize}

**The size of the arm opening for sleeveless designs**
- Type: **Percentage**
- Default: **60%**
- Minimum: **20%**
- Maximum: **80%**

<Sleevelessopeningsize />

### Waist fitting dart percentage {#fitwaistdartpct}

**How much of the waist should be fitted using the dart**
- Type: **Percentage**
- Default: **50%**
- Minimum: **0%**
- Maximum: **100%**

<Fitwaistdartpct />

### Hem allowance {#hemallowance}

**The size of the hem allowance as a percentage of the seam allowance**
- Type: **Percentage**
- Default: **300%**
- Minimum: **0%**
- Maximum: **600%**

<Hemallowance />

### Sleeve width {#sleevewidth}

**The width of the sleeve opening**
- Type: **Percentage**
- Default: **30%**
- Minimum: **-10%**
- Maximum: **200%**

<Sleevewidth />

### Sleeve width guarantee {#sleevewidthguarantee}

**Controls how much of the sleeve width will be guaranteed. This determines how much we can alter the sleeve width to fit the sleeve in the armhole.**
- Type: **Percentage**
- Default: **85%**
- Minimum: **25%**
- Maximum: **100%**

<Sleevewidthguarantee />

### Sleevecap back X {#sleevecapbackfactorx}

**Controls the placement of the sleevecap back pitchpoint on the X-axis (horizontal)**
- Type: **Percentage**
- Default: **60%**
- Minimum: **35%**
- Maximum: **65%**

<Sleevecapbackfactorx />

### Sleevecap back Y {#sleevecapbackfactory}

**Controls the placement of the sleevecap back pitchpoint on the Y-axis (vertical)**
- Type: **Percentage**
- Default: **33%**
- Minimum: **30%**
- Maximum: **65%**

<Sleevecapbackfactory />

### Sleevecap ease {#sleevecapease}

**The amount by which the sleevecap seam is longer than the armhole seam.**
- Type: **Percentage**
- Default: **0%**
- Minimum: **0%**
- Maximum: **10%**

<Sleevecapease />

### Sleevecap front X {#sleevecapfrontfactorx}

**Controls the placement of the sleevecap front pitchpoint on the X-axis (horizontal)**
- Type: **Percentage**
- Default: **55%**
- Minimum: **35%**
- Maximum: **65%**

<Sleevecapfrontfactorx />

### Sleevecap front Y {#sleevecapfrontfactory}

**Controls the placement of the sleevecap front pitchpoint on the Y-axis (vertical)**
- Type: **Percentage**
- Default: **33%**
- Minimum: **30%**
- Maximum: **65%**

<Sleevecapfrontfactory />

### Sleevecap Q1 offset {#sleevecapq1offset}

**Controls the curvature of the sleevecap in the first quadrant (front armhole)**
- Type: **Percentage**
- Default: **1%**
- Minimum: **0%**
- Maximum: **7%**

<Sleevecapq1offset />

- Minimum: **4%**
- Maximum: **20%**

<Sleevecapq1spread1 />

<Sleevecapq1spread2 />

- Maximum: **20%**

<Sleevecapq2spread1 />

### Sleevecap Q2 upward spread {#sleevecapq2spread2}

- Default: **10%**
- Minimum: **4%**
- Maximum: **20%**

<Sleevecapq2spread2 />

### Sleevecap Q3 offset {#sleevecapq3offset}

<Sleevecapq3offset />

### Sleevecap top X {#sleevecaptopfactorx}

**Controls the horizontal location of the sleevecap top.**
- Type: **Percentage**
- Default: **50%**
- Minimum: **25%**
- Maximum: **75%**

<Sleevecaptopfactorx />

### Sleevecap top Y {#sleevecaptopfactory}

**Controls the height of the sleevecap. A higher value results in a higher and more narrow sleevecap.**
- Type: **Percentage**
- Default: **45%**
- Minimum: **35%**
- Maximum: **125%**

<Sleevecaptopfactory />

### Extra bust ease {#extrabustease}

**Extra amount of ease to consider when drafting the full bust adjustment. This is added on top of the chest ease and will add extra compression to the bust when negative.**
- Type: **Percentage**
- Default: **-5%**
- Minimum: **-15%**
- Maximum: **15%**

<Extrabustease />

### Bust dart {#dart}

**Enable or disable a bust dart on the front part**
- Type: **Boolean**
- Default: **true**

<Dart />

### Ribbing stretch {#ribbingstretch}

**How much the ribbing is stretched relative to the main fabric**
- Type: **Percentage**
- Default: **5%**
- Minimum: **0%**
- Maximum: **30%**

<Ribbingstretch />

## Style {#style}
### Construction {#construction}

**Sets the type of the top (t-shirt, raglan, sleeveless, etc.)**
- Type: **List**
- Default: **set-in**
- options:
  - set-in
  - dolman
  - raglan
  - sleeveless
  - racerback

<Construction />

### Armhole depth {#armholedepth}

**Controls the depth of the armhole. Higher values make a deeper armhole.**
- Type: **Percentage**
- Default: **10%**
- Minimum: **0%**
- Maximum: **40%**

<Armholedepth />

### Neck opening based on {#neckbasedon}

**Which measurement to use for the neck opening**
- Type: **List**
- Default: **head**
- options:
  - neck
  - head
  - waist
  - seat

<Neckbasedon />

### Neck opening size {#neckopeningsize}

**Determines the circumference of the neck opening**
- Type: **Percentage**
- Default: **80%**
- Minimum: **65%**
- Maximum: **150%**

<Neckopeningsize />

### Neck width {#neckwidth}

**Make the neck opening deep and narrow, or wide and shallow.**
- Type: **Percentage**
- Default: **60%**
- Minimum: **0%**
- Maximum: **130%**

<Neckwidth />

### Back neck depth {#backneckcutout}

**The depth of the back neck relative to the front**
- Type: **Percentage**
- Default: **30%**
- Minimum: **5%**
- Maximum: **200%**

<Backneckcutout />

### Neck opening shoulder angle {#shoulderangle}

**At which angle the neck opening goes over your shoulder**
- Type: **Degrees**
- Default: **25°**
- Minimum: **0°**
- Maximum: **35°**

<Shoulderangle />

### Front neck opening shape {#frontneckopening}

**Change the shape of the front neck opening**
- Type: **Percentage**
- Default: **100%**
- Minimum: **0%**
- Maximum: **200%**

<Frontneckopening />

### Length {#lengthbelowwaist}

**The length of the top, measured from the waist down**
- Type: **Percentage**
- Default: **75%**
- Minimum: **-15%**
- Maximum: **100%**

<Lengthbelowwaist />

### Straight hem {#straighthem}

**If the bottom hem should be kept straight or in an A-line shape**
- Type: **Boolean**
- Default: **false**

<Straighthem />

### Ribbing height {#ribbingheight}

**Width of the ribbing, set to 0 to disable**
- Type: **Percentage**
- Default: **0%**
- Minimum: **0%**
- Maximum: **1000%**

<Ribbingheight />
