- [ ] **Step 1: Write `scripts/rasterize.py`**

```python
import json, sys
from pathlib import Path
import fitz  # pymupdf

def main():
    cfg = json.loads(Path(sys.argv[1]).read_text(encoding='utf-8'))
    pdf = fitz.open(cfg['pdf'])
    out = Path(cfg['out_dir'])
    out.mkdir(parents=True, exist_ok=True)
    first, last = cfg['pages']
    target_dpi = cfg.get('dpi', 300)
    max_pixels = cfg.get('max_pixels', 60_000_000)
    for pno in range(first - 1, last):
        page = pdf[pno]
        w_in = page.rect.width / 72
        h_in = page.rect.height / 72
        dpi = target_dpi
        if w_in * h_in * dpi * dpi > max_pixels:
            dpi = int((max_pixels / (w_in * h_in)) ** 0.5)
        pix = page.get_pixmap(dpi=dpi)
        f = out / f'page-{pno + 1:04d}.png'
        pix.save(f)
        print(f'{f} {pix.width}x{pix.height} @ {dpi}dpi')

main()
```

- [ ] **Step 2: Write `scripts/ocr.py`**

```python
import json, re, sys
from pathlib import Path
from PIL import Image
import pytesseract

Image.MAX_IMAGE_PIXELS = None
CJK = r'[\u4e00-\u9fff\u3040-\u30ff\uff00-\uffef\u3000-\u303f]'

def strip_cjk_spaces(text):
    prev = None
    while prev != text:
        prev = text
        text = re.sub(f'({CJK}) +({CJK})', r'\1\2', text)
    return text

def main():
    cfg = json.loads(Path(sys.argv[1]).read_text(encoding='utf-8'))
    for img in cfg['images']:
        txt = pytesseract.image_to_string(Image.open(img), lang=cfg.get('lang', 'chi_sim'))
        out = Path(img).with_suffix('.txt')
        out.write_text(strip_cjk_spaces(txt), encoding='utf-8')
        print(out)

main()
```

# Pattern book extraction (daban)

Books: `C:\Users\Lemonci\Documents\pattern_making\clothing_books` (READ-ONLY).
Temp output: the session job tmp dir. Python via `conda run -n daban python ...`.

## Windows gotcha

Never type Chinese paths on a PowerShell command line — pass them through a UTF-8
JSON args file written with the Write tool.

## Workflow

1. **Locate**: rasterize the front matter (pages 1–12), read the TOC, find the
   chapter. Determine the printed-page → PDF-page offset by rasterizing one
   candidate page and comparing its printed folio number. Record the offset.
2. **Rasterize** the chapter: `scripts/rasterize.py <args.json>` with
   `{"pdf", "pages": [first, last], "out_dir", "dpi"?: 300, "max_pixels"?: 60000000}`.
   DPI auto-adapts down for oversized pages (some pages are 51×73 in).
3. **Read**: the drafting DIAGRAMS, read visually, are the primary source of
   truth. OCR (`scripts/ocr.py`, lang chi_sim, inter-CJK spaces auto-stripped)
   supports the running text. Where diagram and text disagree, flag it as an
   ambiguity — do not pick silently.
4. **Write the spec** at `daban/docs/patterns/<name>.md` (template below) and
   add/update the design's row in `daban/docs/patterns/INDEX.md`. Add any new
   CN terms to `daban/docs/patterns/glossary.md`.
5. **Gate**: check the extracted formulas against the
   `pattern-making-principles` skill; record the result in the spec's Review
   section. Ambiguities go to the user (CLAUDE.md rule 5) before implementation.

import { globDir, copyFolderRecursively, rm, templateOut, writeJsonFile } from './scripts/fs.mjs'

await copyFolderRecursively(src, target)
const files = (await globDir(target, '**/*.mustache'))
  .map((file) => file.split(`designs${path.sep}${name}${path.sep}`).pop().split(path.sep))
  .map((found) => ({
    from: [...target, ...found],
    to: [...target, ...found.slice(0, -1), found.slice(-1).pop().split('.mustache')[0]],
  }))
for (const file of files) {
  await templateOut(file.from, file.to, { name, Name })
  await rm(file.from)
}
await writeJsonFile([...target, 'about.json'], {
  id: name,
  code: 'lemonci',
  design: 'AUTHOR_FROM_QUN_MD_SOURCE_HEADER',
  description: 'A straight skirt block drafted with the classic British pattern cutting method',
  name: 'Qun Skirt Block',
  difficulty: 2,
  tags: ['women', 'skirts'],
  techniques: ['darts'],
  version: conf.version,
  pkg: `@freesewing/${name}`,
  collection: true,
})
console.log('scaffolded designs/qun')

```js
import { expect } from 'chai'
import { Qun } from '../src/index.mjs'

// Standard-size measurements from docs/patterns/qun.md §Worked example (mm)
const measurements = {
  waist: /* qun.md */,
  seat: /* qun.md */,
  waistToSeat: /* qun.md */,
  waistToKnee: /* qun.md */,
}

// Book's worked arithmetic from the same table (mm)
const expected = {
  backSeatWidth: /* qun.md */,
  frontSeatWidth: /* qun.md */,
  backWaistToSeat: /* qun.md */,
  skirtLength: /* qun.md */,
  backDartIntake: /* qun.md */,
  frontDartIntake: /* qun.md */,
}

const TOL = 2 // mm — spec success criterion

describe('Qun numeric oracle (book worked example)', () => {
  const pattern = new Qun({ measurements })
  pattern.draft()

  it('drafts without errors', () => {
    expect(pattern.setStores[0].logs.error.length).to.equal(0)
  })

  const back = () => pattern.parts[0]['qun.back'].points
  const front = () => pattern.parts[0]['qun.front'].points

  it('back seat width matches the book', () => {
    expect(Math.abs(back().cbSeat.dist(back().sideSeat) - expected.backSeatWidth)).to.be.at.most(TOL)
  })
  it('front seat width matches the book', () => {
    expect(Math.abs(front().cfSeat.dist(front().sideSeat) - expected.frontSeatWidth)).to.be.at.most(TOL)
  })
  it('waist-to-seat depth matches the book', () => {
    expect(Math.abs(back().cbWaist.dist(back().cbSeat) - expected.backWaistToSeat)).to.be.at.most(TOL)
  })
  it('skirt length matches the book', () => {
    expect(Math.abs(back().cbWaist.dist(back().cbHem) - expected.skirtLength)).to.be.at.most(TOL)
  })
  it('back dart intake matches the book', () => {
    expect(Math.abs(back().dart1Left.dist(back().dart1Right) - expected.backDartIntake)).to.be.at.most(TOL)
  })
  it('front dart intake matches the book', () => {
    expect(Math.abs(front().dart1Left.dist(front().dart1Right) - expected.frontDartIntake)).to.be.at.most(TOL)
  })
})
```

Note: the part key inside `pattern.parts[0]` is the part `name` (`qun.back`); verify the exact key at first run and adjust the accessor once if needed (this is an accessor detail, not an oracle-number change).
