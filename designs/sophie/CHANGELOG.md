# Change log for: @freesewing/sophie


## 4.9.0 (2026-05-25)

### Changed

 - Change how seam allowance is drawn on front and back panels

### Fixed

 - Fix seam allowance showing up on the fold

## 4.5.0 (2026-02-21)

### Fixed

 - Fixed armholewidth front and back (#722)
 - Enforce the correct draft order (#734)

## 4.4.0 (2025-11-06)

### Added

 - Initial release of Sophie, a slip dress design

## 3.0.0 (2023-09-30)

### Changed

 - All FreeSewing packages are now ESM only.
 - All FreeSewing packages now use named exports.
 - Dropped support for NodeJS 14. NodeJS 18 (LTS/hydrogen) or more recent is now required.


This is the **initial release**, and the start of this change log.

> Prior to version 2, FreeSewing was not a JavaScript project.
> As such, that history is out of scope for this change log.
