# Change log for: @freesewing/sunny


## 4.7.0 (2026-03-27)

### Fixed

 - Make skirts tag plural in line with other designs

## 4.6.0 (2026-03-08)

### Fixed

 - Make pleat points available when complete is false

## 4.5.0 (2026-02-21)

### Fixed

 - Don't skip creating points and paths in base part if not complete
 - Fix missing pleat points when drafting when complete is false

## 4.4.3 (2025-11-29)

### Fixed

 - Add missing @freesewing/plugin-path-utils dependency

## 4.2.0 (2025-08-16)

### Added

 - Initial release of Sunny, an 18th century split side skirt

## 3.0.0 (2023-09-30)

### Changed

 - All FreeSewing packages are now ESM only.
 - All FreeSewing packages now use named exports.
 - Dropped support for NodeJS 14. NodeJS 18 (LTS/hydrogen) or more recent is now required.


This is the **initial release**, and the start of this change log.

> Prior to version 2, FreeSewing was not a JavaScript project.
> As such, that history is out of scope for this change log.
